# Hardware acceptance

CI evidence is not hardware evidence.

Required evidence labels:

- CI VERIFIED
- EMULATOR VERIFIED
- PHYSICAL DEVICE VERIFIED

The physical matrix will cover API 23, 24-27, 28, 29+ and current Android; LEGACY/LIMITED/FULL/LEVEL_3 where available; one-camera, multi-public-ID and logical-multi-camera devices; RAW/no-RAW; RAW without manual sensor; unusual orientation; fixed focus; and external camera where practical.

Qualcomm, Exynos, MediaTek, Tensor and different sensor vendors belong only in the QA matrix, never runtime routing logic.
